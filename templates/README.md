# Шаблоны документов

Каждый вид договора — папка: `contract.docx`, `act.docx`, `fields.json`.

## Как устроено поле
Поле — элемент управления содержимым Word (серый прямоугольник). У каждого поля есть **тег** — ключ, по которому бот подставляет значение (`price`, `services`, `customer` …). Текст внутри поля в шаблоне — просто подсказка для автора; бот заменит его целиком.

## Как автору добавить или изменить поле в Word
1. Вкладка «Разработчик» (если её нет: Файл → Параметры → Настроить ленту → «Разработчик»).
2. Выделить место → «Элемент управления содержимым „обычный текст“».
3. «Свойства» → «Тег»: латиницей, как в `fields.json` (например `price`). «Название» — по-русски, для себя.
4. Если поле новое — сообщить разработчику ключ, вопрос пользователю и формат: он добавит его в `fields.json`.

Одно и то же значение (например номер договора) можно ставить в нескольких местах — достаточно одинакового тега.

## Проверка
`pytest tests/test_docx_fill.py` — теги шаблона совпадают с `fields.json`.
`python tools/fill_example.py` — шаблон заполняется примером, PDF в `out/example/`.

## uslugi — оказание услуг (версия 1, 29.10.2026)
Файлы автора, без изменения текста и оформления. При подготовке к репозиторию: приняты пустые служебные правки, удалены старые комментарии, полям проставлены теги, в списке НДС акта обновлены ставки (22 %, 7 %, 5 %; бот всё равно подставляет значение сам).
