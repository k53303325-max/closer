cd "/Users/mark/Desktop/Проекты/Closer"

```bash

```

## Чеклист

| # | Проверка |
|---|----------|
| 1 | Профиль бота — короткое описание |
| 2 | Пустой чат — длинное описание |
| 3 | Start → приветствие + 4 кнопки меню |
| 4 | «Составить» / «Мои» / «Профиль» → «Скоро будет» + «В главное меню» |
| 5 | «Помощь» → 3–4 строки + «В главное меню» |
| 6 | «В главное меню» или /start → снова приветствие и кнопки |
| 7 | Произвольный текст → «Выберите действие в меню» + меню |
| 8 | Правки только в `texts/ru.yaml` |

Тексты кнопок: `menu.*`, ответы: `bot.soon`, `bot.use_menu`, `help.text`.
