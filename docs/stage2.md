# Этап 2 — черновик договора (кнопка «Составить договор»)

## Подготовка

```bash
cd "/Users/mark/Desktop/Проекты/Closer"
docker compose up -d postgres
alembic upgrade head
# PD_ENCRYPTION_KEY и DATABASE_URL в .env
docker compose up bot
```

Локально без Docker: PostgreSQL + LibreOffice (`soffice`) для PDF.

## Сценарий проверки

1. «Составить договор» → при первом входе ПЭП (галочка + «Продолжить») → контакт.
2. Роль «Оказываю» / «Заказываю».
3. Описание сделки одним сообщением.
4. При необходимости — уточнения по одному полю; оплата — только кнопками.
5. Профиль (только нужные поля; у исполнителя — реквизиты и НДС для ИП/ООО).
6. Карточка черновика + PDF с водяным знаком «ЧЕРНОВИК».
7. «Изменить» → поле → новая карточка и PDF.
8. «Подписать и отправить» → «Скоро будет».
9. «Отмена» на любом шаге → меню, черновик сохранён.
10. Повторный вход → «Продолжить» / «Начать новый».

Тексты: `texts/ru.yaml`. Шаблон: `templates/uslugi/contract.docx`, поля: `fields.json`.
